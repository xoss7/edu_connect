## Firebase

The app is wired to the `educonnect-85e03` Firebase project via
`lib/firebase_options.dart` (generated by `flutterfire configure`,
committed since it holds no secrets — the values are safe to ship in a
client app). Android is fully configured (`android/app/google-services.json`).
iOS has `FirebaseOptions` generated but no `GoogleService-Info.plist` yet —
re-run `flutterfire configure` and select iOS if/when building for it.

To point the app at a different Firebase project, run
`flutterfire configure` again.
